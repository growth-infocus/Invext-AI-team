To enable Teams notifications, configure your Incoming Webhook URL:

  1. Open Microsoft Teams → Go to your Engineering channel
  2. Click ··· → Connectors → Incoming Webhook → Configure
  3. Name it "AI Agent Team", copy the webhook URL
  4. Add to your .env: TEAMS_WEBHOOK_URL=https://...
  5. Restart the manager container: docker compose restart manager
